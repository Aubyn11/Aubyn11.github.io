27. 移除元素

难度：简单
题目要求：
给你一个数组nums和一个值val，要原地移除所有数值等于val的元素，并返回移除后数组的新长度。
不要使用额外的数组空间，必须仅使用O（1）额外空间并原地修改输入数组。

示例1：

输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2]

示例2：

输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5, nums = [0,1,4,0,3]

题解

利用快慢指针，当快指针指向的元素下标小于数组长度进行循环，如果快指针指向的元素不等于val的数值，就让慢指针指向的元素等于快指针指向的元素，慢指针自增，判断结束之后快指针自增，最后返回慢指针的值

想法代码

public static int RemoveElement(int[] nums, int val)
{
    int slow = 0;
    int fast = 0;
    while (fast < nums.Length)
    {
        if (nums[fast] != val)
        {
            nums[slow] = nums[fast];
            slow++;
        }
        fast++;
    }
    return slow;
}

28. 找出字符串中第一个匹配项的下标

难度：简单
题目要求：
给顶两个字符串haystack和needle，在haystack字符串中找出needle字符串的第一个匹配项的下标（下标从0开始）。如果needle不是haystack的一部分，则返回-1。

示例1：

输入：haystack = “sadbutsad”, needle = “sad”
输出：0

示例2：

输入：haystack = “leetcode”, needle = “leeto”
输出：-1

题解

直接使用KMP算法即可，但是需要加上两个判定条件，如果needle为空就返回0，如果needle的长度大于haystack的长度或者haystack为空，就返回-1

想法代码

public int StrStr(string haystack, string needle)
{

    if (string.IsNullOrEmpty(needle))
    {
        return 0;
    }

    if (needle.Length > haystack.Length || string.IsNullOrEmpty(haystack))
    {
        return -1;
    }

    return KMP(haystack, needle);
}
private int KMP(string haystack, string needle)
{
    int[] next = GetNext(needle);
    int i = 0;
    int j = 0;
    while (i < haystack.Length)
    {
        if (haystack[i] == needle[j])
        {
            j++;
            i++;
        }
        if (j == needle.Length)
        {
            return i - j;
        }
        else if (i < haystack.Length && haystack[i] != needle[j])
        {
            if (j != 0)
            {
                j = next[j - 1];
            }
            else
            {
                i++;
            }
        }
    }
    return -1;
}

private int[] GetNext(string str)
{
    int[] next = new int[str.Length];
    next[0] = 0;
    int i = 1;
    int j = 0;
    while (i < str.Length)
    {
        if (str[i] == str[j])
        {
            j++;
            next[i] = j;
            i++;
        }
        else
        {
            if (j == 0)
            {
                next[i] = 0;
                i++;
            }
            else
            {
                j = next[j - 1];
            }
        }
    }
    return next;
}
