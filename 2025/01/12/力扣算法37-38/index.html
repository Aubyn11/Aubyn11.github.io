解数独

难度：困难
题目要求：
编写一个程序，通过填充空格来解决数独问题。
数独的解法需 遵循如下规则：

  1. 数字 1-9 在每一行只能出现一次。
  2. 数字 1-9 在每一列只能出现一次。
  3. 数字 1-9 在每一个以粗实线分隔的 3x3 宫内只能出现一次。（请参考示例图）
    数独部分空格内已填入了数字，空白格用 '.' 表示。

示例1：

输入：board = [[“5”,”3”,”.”,”.”,”7”,”.”,”.”,”.”,”.”],[“6”,”.”,”.”,”1”,”9”,”5”,”.”,”.”,”.”],[“.”,”9”,”8”,”.”,”.”,”.”,”.”,”6”,”.”],[“8”,”.”,”.”,”.”,”6”,”.”,”.”,”.”,”3”],[“4”,”.”,”.”,”8”,”.”,”3”,”.”,”.”,”1”],[“7”,”.”,”.”,”.”,”2”,”.”,”.”,”.”,”6”],[“.”,”6”,”.”,”.”,”.”,”.”,”2”,”8”,”.”],[“.”,”.”,”.”,”4”,”1”,”9”,”.”,”.”,”5”],[“.”,”.”,”.”,”.”,”8”,”.”,”.”,”7”,”9”]]
输出：[[“5”,”3”,”4”,”6”,”7”,”8”,”9”,”1”,”2”],[“6”,”7”,”2”,”1”,”9”,”5”,”3”,”4”,”8”],[“1”,”9”,”8”,”3”,”4”,”2”,”5”,”6”,”7”],[“8”,”5”,”9”,”7”,”6”,”1”,”4”,”2”,”3”],[“4”,”2”,”6”,”8”,”5”,”3”,”7”,”9”,”1”],[“7”,”1”,”3”,”9”,”2”,”4”,”8”,”5”,”6”],[“9”,”6”,”1”,”5”,”3”,”7”,”2”,”8”,”4”],[“2”,”8”,”7”,”4”,”1”,”9”,”6”,”3”,”5”],[“3”,”4”,”5”,”2”,”8”,”6”,”1”,”7”,”9”]]

题解：

使用递归算法，创建三个字典列表，分别为liRow，liCol，liBox，分别表示九行，九列和九个格子，再定义一个用来临时存储结果的二维数组boardAllres

主要步骤如下：

  • 先判断一开始总共由多少个数字：
    • 创建一个字典dicAllTemp来存储数字是否出现过
    • 先对dicAllTemp赋初始值为false，然后将对应的字典索引值添加到liRow，liCol，liBox中
    • 对整个集合进行遍历，如果当前元素的值不为'.'，那么就将当前单元格所对应的三个字典列表全部设置为True，并让计数hasNumCount自增
  • 之后就要完成回溯函数
    • 先进行判断，如果计数$hasNumCount == 81$，那么直接将结果存储到boardAllres中并返回
    • 遍历当前集合，如果当前元素为'.'，那么就查出该行还未使用过的数字，判断它位于哪一个格子，将hasNumCount自增，并将此单元格再三个字典列表对应的值设置为True并将结果存储到传入的二维数组board中
    • 对回溯函数本身进行递归，如果符合要求就返回True，不符合要求就撤回当前操作
  • 当函数遍历完成，就可以将boardAllres的结果赋值给最终结果

想法代码：

class Solution
{
    List<Dictionary<int, bool>> liRow = new List<Dictionary<int, bool>>();
    List<Dictionary<int, bool>> liCol = new List<Dictionary<int, bool>>();
    List<Dictionary<int, bool>> liBox = new List<Dictionary<int, bool>>();
    char[][] boardAllres = null;

    public static void Main(String[] args)
    {
        char[][] board = new char[9][]
        {
            new char[] { '5', '3', '.', '.', '7', '.', '.', '.', '.' },
            new char[] { '6', '.', '.', '1', '9', '5', '.', '.', '.' },
            new char[] { '.', '9', '8', '.', '.', '.', '.', '6', '.' },
            new char[] { '8', '.', '.', '.', '6', '.', '.', '.', '3' },
            new char[] { '4', '.', '.', '8', '.', '3', '.', '.', '1' },
            new char[] { '7', '.', '.', '.', '2', '.', '.', '.', '6' },
            new char[] { '.', '6', '.', '.', '.', '.', '2', '8', '.' },
            new char[] { '.', '.', '.', '4', '1', '9', '.', '.', '5' },
            new char[] { '.', '.', '.', '.', '8', '.', '.', '7', '9' }
        };
        Solution solution = new Solution();
        solution.SolveSudoku(board);
        foreach (var a in board)
        {
            foreach (var b in a)
            {
                Console.Write(b + " , ");
            }
            Console.WriteLine();
        }
    }

    public void SolveSudoku(char[][] board)
    {
        int count = 0;
        Dictionary<int, bool> dic = new Dictionary<int, bool>();
        for (int i = 1; i <= 9; i++)
        {
            dic.Add(i, false);
        }
        for (int i = 0; i < 9; i++)
        {
            liRow.Add(new Dictionary<int, bool>(dic));
            liCol.Add(new Dictionary<int, bool>(dic));
            liBox.Add(new Dictionary<int, bool>(dic));
        }
        for (int i = 0; i < board.Length; i++)
        {
            for (int j = 0; j < board[0].Length; j++)
            {
                if (board[i][j] != '.')
                {
                    int temp = board[i][j] - 48;
                    liRow[i][temp] = true;
                    liCol[j][temp] = true;
                    int acount = (i / 3) * 3 + j / 3;
                    liBox[acount][temp] = true;
                    count++;
                }
            }
        }
        ReCursive(board, count, 0, 0);
        board = boardAllres;
    }
    public bool ReCursive(char[][] board, int acount, int i, int j)
    {
        if (acount == 81)
        {
            boardAllres = board;
            return true;
        }
        for (; i < board.Length; i++)
        {
            for (j = 0; j < board[0].Length; j++)
            {
                if (board[i][j] == '.')
                {
                    List<int> liRes = liRow[i].Where(e => e.Value == false).Select(e => e.Key).ToList();
                    foreach (var item in liRes)
                    {
                        int count = (i / 3) * 3 + j / 3;
                        if (liCol[j][item] == false && liBox[count][item] == false && liRow[i][item] == false)
                        {
                            acount++;
                            liRow[i][item] = true;
                            liCol[j][item] = true;
                            liBox[count][item] = true;
                            board[i][j] = (char)(item + 48);
                            if (ReCursive(board, acount, i, 0))
                            {
                                return true;
                            }
                            acount--;
                            board[i][j] = '.';
                            liRow[i][item] = false;
                            liCol[j][item] = false;
                            liBox[count][item] = false;
                        }
                    }
                    return false;
                }
            }
        }
        return false;
    }
}

38. 外观数列

难度：中等
题目要求：
给定一个正整数 n ，输出外观数列的第 n 项。

「外观数列」是一个整数序列，从数字 1 开始，序列中的每一项都是对前一项的描述。

你可以将其视作是由递归公式定义的数字字符串序列：

  • countAndSay(1) = "1"
  • countAndSay(n) 是对 countAndSay(n-1) 的描述，然后转换成另一个数字字符串。

前五项如下：

  1. 1

  2. 11

  3. 21

  4. 1211

  5. 111221

第一项是数字 1
描述前一项，这个数是 1 即 “ 一 个 1 ”，记作 "11"
描述前一项，这个数是 11 即 “ 二 个 1 ” ，记作 "21"
描述前一项，这个数是 21 即 “ 一 个 2 + 一 个 1 ” ，记作 “1211"
描述前一项，这个数是 1211 即 “ 一 个 1 + 一 个 2 + 二 个 1 ” ，记作 “111221"

要 描述 一个数字字符串，首先要将字符串分割为 最小 数量的组，每个组都由连续的最多 相同字符 组成。然后对于每个组，先描述字符的数量，然后描述字符，形成一个描述组。要将描述转换为数字字符串，先将每组中的字符数量用数字替换，再将所有描述组连接起来。

示例1：

输入：n = 1
输出：“1”

示例2

输入：n = 4
输出：“1211”

题解：

直接进行遍历，定义字符串$S_i$表示countAndSay(i)，如果要求得到$S_n$，则需要求出$S_{n-1}$，然后按照上述的方法生成，即从左到右依次扫描字符串$S_{n-1}$中连续相同的字符的最大数目，然后将字符的统计数目转化为数字字符再连接上对应的字符，已知$S_1$为"1"，就可以依次生成其他

想法代码

using System.Text;

class Solution
{
    public static void Main(String[] args)
    {
        int n = 4;
        string res = CountAndSay(n);
        Console.WriteLine(res);
    }

    public static string CountAndSay(int n)
    {
        string str = "1";
        for (int i = 2; i <= n; ++i)
        {
            StringBuilder sb = new StringBuilder();
            int start = 0;
            int pos = 0;

            while (pos < str.Length)
            {
                while (pos < str.Length && str[pos] == str[start])
                {
                    pos++;
                }
                sb.Append(pos - start).Append(str[start]);
                start = pos;
            }
            str = sb.ToString();
        }

        return str;
    }
}
